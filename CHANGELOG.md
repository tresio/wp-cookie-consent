# Changelog

All notable changes to this plugin are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[semantic versioning](https://semver.org/).

## [Unreleased]

### Changed

- README: turn on auto-updates during install, and how updates behave with
  auto-updates on or off. No code changes; this release also checks that
  updates reach installed sites.

## [0.3.0]

### Added

- Self-updating from GitHub Releases. New versions appear on the Plugins
  screen like any other plugin update.

### Changed

- Moved into its own public repository, `tresio/wp-cookie-consent`.

## [0.2.0]

### Changed

- Google gets an Essential checkbox like WhatConverts, with Consent Mode as its
  own checkbox. Built-in tags are listed IDs first.

## [0.1.0]

- Initial release: banner, preferences panel, Google modes, WhatConverts, Meta
  Pixel, gated and essential scripts, and the auto-created cookie policy page.
